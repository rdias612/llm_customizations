# Antigravity

Customizações para o Antigravity, organizadas em plugins. Cada plugin tem manifesto, regras, subagentes, skills e assets próprios.

| Plugin | Versão | Descrição | Documentação |
| --- | --- | --- | --- |
| agent-orchestrator | 1.10.0 | Orquestração de subagentes para planejamento, debate, execução por etapa com revisão e commit atômico, ideação, auditoria de code slop e geração divergente. | [agent-orchestrator/README.md](agent-orchestrator/README.md) |
| concept-prototyper | 1.1.0 | Prototipagem conceitual com subagentes para mockups HTML, slides, documentação e conceitos genéricos, sem alterar o código de produção. | [concept-prototyper/README.md](concept-prototyper/README.md) |

Estrutura comum de cada plugin: `plugin.json`, `README.md`, `rules/AGENTS.md`, `agents/`, `skills/` e `assets/`.
